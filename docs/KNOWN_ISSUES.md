# Known limitations and follow-up validation

- Persian mapping is experimental and not independently verified.
- Windows installer is unsigned; no automatic update system is implemented.
- Browser file-URL storage is browser-dependent; desktop/browser histories are separate.
- Complete all 14 story contacts in a real user acceptance run.
- Verify audible quality, keyboard timing and PDF output on target devices.
- Verify cold-restart persistence and full install/uninstall on a clean Windows 10/11 x64 machine.

The latter items describe test coverage gaps, not confirmed failures. Release naming does not imply that these checks have passed. Story scenarios are fictional and not emergency instructions.
