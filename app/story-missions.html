    MOWJ / STORY MISSIONS

    You are the only link.

    The storm has split the coastal radio network. Harbor, the lighthouse and the rescue patrol can hear Control, but cannot reach one another.

    An unknown distress signal has reached Harbor. Receive their Morse messages, translate each word, then relay the complete message to the next station.

    Receive: replay the full message or just the current word. Type your translation and press Enter. The reference sheet contains letters and numbers.

    Transmit: use ← for dot, → for dash, Pause briefly to finish each character automatically, or use Enter. Shift clears only the current character; accepted letters stay safe.
